# Jetson Nano Benchamrks Lab

### Purpose
The purpose of this lab project, is to explore and understand the performance/technical limitations of running neural networks on deployed 'edge' hardware. The equipment in focus is the 'NVIDIA Jetson Nano Super Development Kit'. We use this AI specialized microcontroller and undergo a diagnostic lab to record/observe/analyze measurements and understand it's use case in real world applications.

The `lab_template.md` is generated and built via assistance with AI tools (Claude) - to balance learning/implementation. The `lab.md` is the completed work and contains the result of the findings and conclusions drawn.
